# Earthquake Dashboard — Frontend

Интерфейс на React, TypeScript и Vite: карта Leaflet, сводка за сутки, список землетрясений, фильтры, автоматическое и ручное обновление и состояния загрузки/ошибок. Источник данных — отдельный бэкенд проекта, получающий ленту USGS.

## Запуск в WebStorm

Требуется Node.js 24.11+ (ветка 24.x) и npm.

1. Откройте earthquake-dashboard-backend и запустите `npm run dev` в его терминале.
2. Откройте earthquake-dashboard-frontend отдельным проектом.
3. При первом запуске выполните `npm ci`, затем `npm run dev`.
4. Откройте http://127.0.0.1:5173/.

Оба сервера должны работать одновременно. Остановка каждого: Ctrl+C в соответствующем терминале.

## Подключение к API

Браузер обращается к `/api/earthquakes` на своём адресе. Vite пересылает запрос на http://127.0.0.1:3000, поэтому локально не требуется менять CORS на бэкенде.

Если бэкенд работает на другом адресе, скопируйте `.env.example` в `.env`, измените `BACKEND_URL` и перезапустите фронтенд. Секреты в клиентский код не помещаются.

Данные загружаются при открытии страницы, кнопкой «Обновить данные» и автоматически раз в минуту. Фоновое обновление сохраняет применённые фильтры, текущую выборку и положение карты. Если вкладка скрыта или запрос ещё выполняется, очередная попытка пропускается; после возвращения обновление произойдёт на следующем минутном интервале. При закрытии страницы таймер и запрос отменяются. Успешная загрузка снимает предупреждение об ошибке. При неудачном обновлении уже полученный список остаётся на экране с предупреждением. Время отображается в часовом поясе устройства. Названия мест приходят от USGS, обычно на английском.

## Проверка и сборка

- `npm run build` — проверка типов и production-сборка в `dist`.
- `npm run lint` — проверка исходников.
- `npm run preview` — локальная проверка сборки; бэкенд также должен быть запущен.

Для публикации `dist` на обычном хостинге потребуется настроить пересылку `/api` к развёрнутому бэкенду. Настройка Vite proxy действует только при локальном запуске dev/preview.

[Репозиторий бэкенда](https://github.com/Doctor-Cyclone/earthquake-dashboard-backend).


## Архитектура фронтенда

- `src/App.tsx` — корневой компонент, подключает страницу.
- `src/app/styles` — базовые глобальные стили.
- `src/pages/EarthquakesPage` — композиция экрана.
- `src/components` — общие шапка и подвал.
- `src/features/earthquakes/api` — HTTP-запросы.
- `src/features/earthquakes/model` — типы, хук загрузки и расчёт сводки.
- `src/features/earthquakes/ui` — панель обновления, сводка, таблица и строка события.
- `src/shared/lib` — общие функции форматирования.

Стили компонентов находятся рядом с ними в `*.module.scss` и изолированы через CSS Modules. Глобальные стили ограничены базовой типографикой и сбросом. Компоненты UI получают данные через props; загрузка, отмена запросов и ошибки управляются хуком `useEarthquakes`.

`npm run format` форматирует исходники; `npm run format:check` проверяет форматирование.

## Карта и фильтры

Карта использует Leaflet и тайлы OpenStreetMap с видимой атрибуцией. Для загрузки подложки нужен интернет; API-ключ не требуется. Приложение не запрашивает геолокацию пользователя.
Размер отметки зависит от магнитуды, янтарные отметки соответствуют M ≥ 4,5. Нажатие открывает место, магнитуду, глубину и время. Название события в таблице — кнопка (доступна с клавиатуры), которая выбирает событие и перемещает карту к нему.

Форма поддерживает minMagnitude, maxMagnitude, minDepth, maxDepth. Границы включены, пустые поля не отправляются. Нажмите «Применить», чтобы обновить карту, список и сводку одной выборкой из API. «Сбросить» убирает все ограничения. Изменение полей само по себе запрос не отправляет. Ручное обновление сохраняет применённые фильтры.

Во время применения новых фильтров старая выборка очищается, чтобы не показывать её как результат новых условий. При обычном обновлении прежние данные сохраняются до ответа. При stale: true выводится предупреждение с fetchedAt последней успешной загрузки; данные не объявляются актуальными.

Проверено вручную в браузере: загрузка реального API, магнитуда от 4,5 / глубина до 100 км, выбор события из списка, ошибочный диапазон, сброс, пустая выборка; предупреждение stale проверено на отдельном тестовом ответе. Сборка и линтер проходят.

## График активности

График показывает 24 последовательных часовых интервала до времени формирования ленты (generatedAt). Он использует применённые фильтры и обновляется вместе с картой и списком. Для устаревшего ответа сохраняется его исходный период. Интервалы считаются по абсолютному времени, подписи отображаются в часовом поясе устройства.

Подсказки доступны при наведении и с клавиатуры через Tab; на узком экране график прокручивается горизонтально. Пустая выборка сопровождается пояснением. Новые зависимости не добавлены.

Запуск тестов расчёта интервалов: npm test. Проверяются границы суток и часов, пустая выборка, неверные даты и часовые смещения.
